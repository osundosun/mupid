# 계정 UI와 모바일 메뉴

로그인·로그아웃은 백엔드 연동 전의 UI 미리보기입니다.
닉네임으로 로그인된 모습을 확인하고 로그아웃 화면으로 되돌릴 수 있습니다.
`demoSession`은 React 메모리에만 존재하며 새로고침하면 초기화됩니다.
계정 생성, 인증 요청, 토큰 발급, 로그인 상태 저장, 데이터 접근 제한은 없습니다.
이전 탭 저장소의 데모 로그인 값도 더 이상 읽거나 갱신하지 않습니다.
음악 재생, 좋아요, 구간, 플레이리스트 등 기존 브라우저 로컬 기능은 유지됩니다.
로그아웃 UI는 재생을 중단하거나 음악 기록을 지우지 않습니다.

실제 인증 연동 시 로그인 방식과 API 계약을 정하고 UI 전환 함수를 교체해야 합니다.
서버는 클라이언트의 `demoSession`을 인증 근거로 사용하면 안 됩니다.

메뉴는 PC의 여섯 목적지를 유지합니다.

- PC: 메인 / 탐색 / 플레이어 / 플레이리스트 / 내 취향 / 프로필
- 모바일 하단: 메인 / 탐색 / 플레이어 / 플리 / 내 취향
- 모바일 상단: 로고와 프로필·계정 진입

좋아한 구간 상세는 플레이어를, 유사곡 추천은 탐색을 선택 상태로 표시합니다.
플레이어에서는 미니 플레이어만 생략하고 하단 메뉴는 유지합니다.
모바일 홈의 LP 위에는 취향 리포트 / 좋아한 구간 / 내 플리 / 탐색 / AI 추천
바로가기를 배치합니다. 좋아한 구간은 저장된 구간 모음을 엽니다.
미니 플레이어는 현재 시간·전체 시간과 조절 가능한 진행 바를 표시합니다.
재생 상태 막대는 오디오 재생·일시정지 상태에 연결된 시각적 표시이며 음량 분석은 아닙니다.
동작 줄이기 설정에서는 움직이지 않습니다.
