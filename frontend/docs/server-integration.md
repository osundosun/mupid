# 실제 서버 연결 전 준비

> **인증은 연결되었습니다.** 로그인·로그아웃·회원가입·세션 복원은 실제 Spring API 를
> 호출합니다 (`lib/api/`). 곡 목록·설정·재생은 아직 demo 입니다 — 서버에 곡 조회
> API 가 없어 화면이 `music_id` 를 알 방법이 없기 때문입니다.
> 스트리밍 플레이어 라이브러리는 [player.md](player.md) 를 보세요.

현재 카탈로그·설정 모드는 demo입니다. 화면/재생은 유지하며 서버는 연결하지 않았습니다.

## 연결 구조

화면 → useMupid / 프로필·로그인 컴포넌트 → MupidService → 데모 저장소

- `lib/services/contracts.ts`: 프론트가 사용하는 비동기 서비스 계약과 회원가입 입력 타입.
- `lib/services/index.ts`: 데모 구현, 기존 저장 키 유지, 모드 선택. 브라우저 저장은 여기에서만 접근합니다.
- `lib/mupid-data.ts`: 기존 데모 곡/초기 컬렉션과 공용 음악 계산 함수. 활성 화면은 곡 목록을 모델에서 받습니다.
- `components/mupid-app.tsx`: 초기 조회 로딩·실패·빈 목록·재시도 처리. 빈 목록에서는 플레이어를 생성하지 않습니다.
- 로그인/회원가입/인증은 서버 미연결 상태로 실패합니다. 데모 로그인 성공 처리는 제거했으며 비밀번호를 저장하거나 전송하지 않습니다. 첫 방문자는 로그인 없이 온보딩을 진행합니다.
- 프로필 사진은 데모에서만 JPEG data URL로 로컬 저장합니다. API 구현은 파일 업로드 응답을 화면용 URL로 변환해야 합니다.

## 실제 연결 시

1. 백엔드와 경로, DTO, ID 타입, 오류 형식, 페이지네이션, 세션·CSRF 정책을 합의합니다. 현재 계약은 확정된 백엔드 명세가 아닙니다.
2. `MupidService`를 구현하는 API 어댑터를 추가합니다. `bootstrap()`은 곡 목록과 사용자 설정을 UI 도메인 형식으로 정규화합니다.
3. `createService('api', apiAdapter)`로 바꿉니다. 미구현 API 모드는 오류를 내며 데모로 자동 우회하지 않습니다.
4. `savePreferences`는 현재 하나의 스냅샷 계약입니다. 서버의 플레이리스트/좋아요/프로필별 API로 매핑하거나 변경별 mutation으로 세분화하세요. 저장 요청은 현재 훅에서 순서대로 처리합니다.
5. 실제 인증 연결 시 세션 복원/만료, 사용자별 캐시 초기화, 로그아웃 시 개인정보 제거를 함께 구현합니다. 기존 데모 저장 내용을 사용자 계정에 자동 업로드하지 마세요.
6. 서버 페이징·캐시가 필요해지면 TanStack Query를 도입합니다. 현재 단계에서 라이브러리나 배포 체계는 바꾸지 않았습니다.

시간 값은 초 단위입니다. `Track.duration`, `moment`, 구간 start/end 모두 같습니다. 실제 음원의 길이와 서버 메타데이터를 맞춰야 합니다.

## AI 채팅 — 연결되었습니다

채팅 패널은 `POST /api/v1/ai/chat` 을 부릅니다 (`lib/ai-chat.ts` → `lib/api/endpoints.ts` 의 `api.ai.chat`).
브라우저는 **Spring API 만** 부릅니다 — 게이트웨이 키도 추천 서버 주소도 화면에 두지 않습니다.

- 서버가 대화를 저장하지 않아 이전 대화를 `history` 로 함께 보냅니다. 역할 이름은 서버 enum 이라 `USER`/`AI` 대문자입니다.
- 추천 곡은 `music_id` 로 옵니다. **카탈로그(`lib/stream-catalog.ts`)에서 찾은 곡만** 목록에 남깁니다 — 없는 곡을 그리면 눌러도 재생되지 않는 줄이 생깁니다.
- 서버 쪽 추천은 아직 목업이라 요청과 무관하게 같은 곡이 옵니다. 답변 문장만 매번 달라집니다.
- 추론 모델이라 수 초에서 수십 초가 걸립니다. 요청 타임아웃은 70초이고, 화면을 떠나면 `AbortController` 로 끊습니다.
- 실패는 서버가 준 문구를 그대로 토스트에 띄웁니다(`chatErrorMessage`). "다시 시도해 주세요" 로 뭉뚱그리면 키가 없어 영영 되지 않는 상황에도 계속 누르게 됩니다.

`lib/mupid-data.ts` 의 `deriveChatRecommendations` 는 이제 채팅이 쓰지 않습니다 (순수 함수와 시험만 남아 있습니다).
