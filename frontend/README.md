# MUPID Production

기존 MUPID 프로토타입에서 분리한 본개발용 프로젝트입니다.

## 시작하기

```bash
npm install
npm run dev
```

웹 배포는 지금까지와 같습니다. 모바일 앱은 같은 화면 코드를 Tauri 로 감싼 것이고,
셸은 저장소 루트의 `app/` 에 있습니다.

```bash
npm run build:static   # 정적 번들 (dist/client) — 앱과 EC2 배포가 함께 씁니다
cd ../app && cargo tauri android dev
```

화면 코드에는 플랫폼 분기가 없습니다. HTTP·저장소·이벤트 전송·앨범 아트 네 군데만
`lib/platform/` 에서 갈립니다 — [docs/app-shell.md](docs/app-shell.md).

## 프로젝트 경계

- 기존 공개 프로토타입과 별도의 Git 저장소로 관리합니다.
- `.openai/hosting.json`은 본개발용 MUPID Studio 사이트에 연결되어 있습니다.
- 기존 공개 프로토타입을 수정하거나 덮어쓰지 않습니다.

## Sky 디자인

하늘·구름 배경, 큐피드 로고와 캐릭터, LP 플레이어, 핑크 구간 강조를 적용했습니다. 기본 UI 글꼴은 Pretendard이며 AI 대화·추천 질문·입력창에만 사용자가 제공한 `GriunGyuwonThin-small.ttf`(그리운 규원체 Thin)를 적용합니다. TTF는 `public/fonts/`에서 직접 제공하며 파일의 실제 굵기 메타데이터인 400으로 등록합니다.

- 모바일: 하단 5개 탭 + 미니 플레이어 + 별도 높이의 플로팅 챗봇. 기기 안전 영역과 작은 화면을 고려합니다.
- 홈 바로가기: 모바일에서 36px 아이콘과 12px 두 줄 이름을 사용합니다. 원래 이름은 접근성 라벨에 유지하며 글자 확대 시 메뉴 열이 재배치됩니다. 추천 카드는 콘텐츠 너비에 따라 4→2→1열로 바뀌고, 배너는 음악 목록 아래에 배치합니다.
- 플레이어: 상단 곡 정보, LP, 탐색 가능한 파형, 재생 버튼, 구간/파생곡 버튼 순서입니다. 모바일에서는 중복 하단 메뉴를 없애고 화면 높이에 따라 LP 크기를 조정합니다. 추천 이유와 구간 시작·종료 숫자 입력은 펼쳐 볼 수 있어 기존 기능을 유지합니다.
- PC/태블릿(768px 이상): 시작 화면을 제외한 모든 앱 페이지에서 동일한 상단 메뉴(메인·탐색·플레이어·플레이리스트·내 취향·프로필)를 사용합니다. 기존 왼쪽 메뉴는 숨기고, 현재 페이지에 맞는 메뉴를 강조합니다. 헤더·본문 너비·미니 플레이어 위치도 통일하며 밝은 하늘 배경과 블루/핑크 포인트를 공통으로 적용합니다. 작은 모바일 화면은 하단 5개 메뉴를 유지합니다.
- PC 홈(1024px 이상): 왼쪽으로 걸친 큰 LP, 중앙 곡 정보/재생 컨트롤, 오른쪽 플레이리스트의 3단 구성입니다. 아래에 검색창과 AI 진입, 추천곡/최근 감상 목록을 이어 배치합니다. 중복 미니 플레이어는 PC 홈에서만 숨기고 재생 위치·볼륨·재생 목록·좋아요·구간 저장은 메인에 유지합니다. 글자 확대 시 2단으로 재배치합니다.
- 재생 목록: 페이지로 들어가지 않고 하단에서 펼쳐지는 독입니다. PC 에서는 오른쪽 끝을 미니 플레이어와 맞추고, 접힐 때도 펼칠 때와 같은 애니메이션으로 사라집니다. 줄 왼쪽 손잡이를 끌어 순서를 바꾸며, 목록의 위아래 가장자리로 끌고 가면 목록이 따라 스크롤됩니다. 손을 뗀 자리에서 순서가 확정되고, 목록 바깥에서 떼도 마찬가지입니다. 담을 자리(맨 위·재생 중인 곡 다음·맨 아래)는 상단 버튼에서 고르며 100곡이 상한입니다. 순서는 사용자별로 서버에 남아 새로고침과 재로그인에도 유지됩니다.
- 탐색: 원형 앨범을 곡선으로 배치하고 선택한 곡에만 밝은 배경을 둡니다. 앨범 선택은 재생과 분리되어 있으며 이전/다음 버튼, 가로 스와이프, 바로 재생·좋아요·곡 상세를 지원합니다. 검색/분위기 필터와 전체 목록 보기, 빈 결과 상태를 유지합니다. 좁은 화면과 큰 글자에서는 세로 배치로 전환하며 모션 감소 설정을 따릅니다.
- 화면: 홈, 탐색, 전체 페이지 플레이어, 구간 저장, 비슷한 구간, 플레이리스트, 취향 리포트, 프로필, 시작 화면.
- URL의 `?view=player` 같은 값으로 화면을 유지하고 브라우저 뒤로 가기를 지원합니다.

## 구현 범위

음원 미리듣기·이전/다음 곡·셔플·반복·구간 선택과 저장·좋아요·플레이리스트 편집·검색을 사용할 수 있습니다. 선호도와 저장 목록은 웹에서는 이 브라우저의 `localStorage`에, 앱에서는 기기의 SQLite에 저장됩니다.

음원과 곡 정보·송폼·파형은 데모입니다. **AI 채팅은 서버에 연결되어 있습니다** — `POST /api/v1/ai/chat` 이 LLM 과 대화하고, 곡 추천은 서버의 tool calling 이 돌려줍니다(`lib/ai-chat.ts`). 다만 **추천 자체는 아직 목업**이라 요청 내용과 무관하게 카탈로그 앞쪽 곡이 옵니다. 서버 쪽 준비가 없으면(키 미설정 등) 채팅은 서버가 준 사유를 그대로 알립니다. 회원 인증, 실제 음악 카탈로그/분석, 서버 동기화, 기간별 리포트 집계는 아직 연결되지 않았습니다. 모바일 앱 패키징은 Tauri 로 연결했습니다 — [docs/app-shell.md](docs/app-shell.md).

## 코드 구조와 검증

- `components/mupid/`: 화면별 UI 및 공통 구성요소
- `hooks/use-mupid.ts`: 재생, 화면 이동, 로컬 저장, AI 채팅 상태
- `lib/mupid-data.ts`: 데모 데이터와 추천 로직
- `lib/explore.ts`: 탐색 필터와 중복 없는 순환 앨범 범위
- `app/mupid.css`: 모바일/PC 레이아웃과 디자인 토큰 사용
- `app/discovery-design.css`: 원형 앨범 탐색과 PC의 카드 없는 섹션 구성
- `components/mupid/desktop-home.tsx`, `app/desktop-home.css`: PC 홈 전용 LP 중심 레이아웃
- `app/sky-shell.css`: 모든 앱 페이지의 PC 공통 메뉴·화면 틀·밝은 하늘 테마

```bash
npx tsc --noEmit --incremental false
npx oxlint hooks/use-mupid.ts components/mupid-app.tsx components/mupid lib/mupid-data.ts
node --experimental-strip-types --test
npm run build          # Cloudflare Worker 배포
npm run build:static   # 정적 번들 (앱 · EC2)
```

앱 셸(Rust·SQLite)은 `cd ../app && cargo test`.

`public/sky-*.png`는 레퍼런스의 분위기를 바탕으로 생성한 원본 이미지입니다. 실제 화면에서는 모바일 전송량을 줄인 WebP 버전을 사용합니다. `scripts/optimize-assets.mjs`는 원본을 보존한 채 배포용 파일을 다시 생성합니다.

### 로고

상단과 시작 화면은 사용자가 제공한 하늘색 큐피드 로고를 공통 `Brand` 컴포넌트로 표시합니다. 배경이 투명한 PNG라 별도 블렌드 없이 하늘 배경 위에 얹습니다.

- `public/mupid-logo-cupid-sky-master.png`: 받은 원본 1710 × 920. 손대지 않고 보존합니다.
- `public/mupid-logo-cupid-sky.png`: 화면에 쓰는 1180 × 600. 원본은 그림 둘레 투명 여백이 넓어 같은 로고 칸에서 글자가 작게 떠 보였습니다. `node scripts/build-logo.mjs`로 그 여백만 잘라내고 3%만 균일하게 되돌립니다. 그림 자체는 자르지 않았습니다.

이전 흑백 PNG와 SVG 로고 파일은 보존합니다.

### 캐릭터 수정

캐릭터는 사용자가 첨부한 오른쪽 옆모습에서 글자와 풍경 배경을 제거한 독립 이미지입니다. `public/mupid-cupid-side.png`는 실제 RGBA 알파를 가진 1254×1254 PNG이며, 화면에서는 최적화한 WebP 버전을 사용합니다. 머리·헤드폰·날개·캐릭터 아래 구름·하트 모양 선은 유지하고 그 외 영역은 투명하게 처리했습니다. 시트를 잘라 표시하던 CSS와 둥근 흐림 마스크는 사용하지 않습니다. 공통 `MupidMascot` 컴포넌트가 모든 캐릭터 위치에 같은 자산을 제공합니다. 메뉴와 안내 문구 등 UI 텍스트는 유지합니다.

이번 자산은 내장 이미지 편집 도구를 사용했고 PNG/WebP의 알파 채널·모서리 투명도·밝은 캐릭터 내부 보존을 검사했습니다. 원본 시트와 이전 `sky-cupid.*`, `mupid-cupid-transparent.*` 파일은 보존했으며 화면에서는 참조하지 않습니다. 세부 제작 요청은 `docs/mascot-side-prompt.md`에 기록했습니다.
