# 음원 특징 추출

**학습 일자** 2026-08-25

## 이 주제를 고른 이유

ACCENCE는 장르만 비슷한 곡이 아니라 사용자가 좋아한 구간과 흐름이 비슷한 곡을 추천하려고 한다. 이를 위해서는 음원을 그대로 비교하지 않고 BPM, 에너지, 리듬, 음색처럼 계산 가능한 값으로 바꿔야 한다.

오늘은 곡 전체와 곡 내부 구간에서 어떤 특징을 추출할지 정리했다.

## 사용할 수 있는 특징

| 특징 | 의미 | 프로젝트에서의 용도 |
|---|---|---|
| BPM | 곡의 전체적인 빠르기 | 템포 기반 탐색 |
| RMS | 구간의 평균적인 에너지 | 잔잔함과 강한 구간 구분 |
| Spectral Centroid | 소리의 무게 중심 주파수 | 밝고 날카로운 음색 구분 |
| Spectral Contrast | 주파수 대역별 강약 차이 | 음색과 편곡 차이 비교 |
| Chroma | 12개 음계의 분포 | 화성 진행이 비슷한 구간 비교 |
| Onset Strength | 소리가 새로 시작되는 강도 | 박자 변화와 타격감 분석 |

BPM 하나만으로 곡의 흐름을 설명하기는 어렵다. 같은 BPM의 곡도 에너지와 음색이 다를 수 있으므로 여러 특징을 함께 사용해야 한다.

## 곡 전체와 구간 특징 분리하기

Track-level 특징은 곡 전체를 대표한다. 전체 BPM, 평균 에너지, 장르 같은 값이 여기에 해당한다. 추천 후보를 빠르게 줄이는 데 사용할 수 있다.

Moment-level 특징은 음원을 일정한 길이로 잘라 계산한다. 예를 들어 5초 단위로 RMS와 Spectral Centroid를 구하면 시간에 따른 변화가 남는다.

```text
00:00~00:05  energy=0.18
00:05~00:10  energy=0.24
00:10~00:15  energy=0.41
00:15~00:20  energy=0.73
```

이 값만 보면 뒤로 갈수록 에너지가 커지는 구간임을 알 수 있다. 현재 값뿐 아니라 이전 구간과의 차이도 저장하면 `잔잔함 → 상승 → 전환` 같은 흐름을 표현할 수 있다.

## librosa로 추출하기

Python에서는 librosa를 이용해 기본 특징을 계산할 수 있다.

```python
import librosa
import numpy as np

y, sr = librosa.load("track.mp3", sr=22050, mono=True)

tempo, _ = librosa.beat.beat_track(y=y, sr=sr)
rms = librosa.feature.rms(y=y)[0]
centroid = librosa.feature.spectral_centroid(y=y, sr=sr)[0]

track_feature = {
    "bpm": float(np.asarray(tempo).squeeze()),
    "rms_mean": float(rms.mean()),
    "rms_std": float(rms.std()),
    "centroid_mean": float(centroid.mean())
}
```

모든 음원은 같은 샘플링 레이트와 채널 수로 맞춰야 한다. 특징별 값의 범위도 다르므로 유사도를 계산하기 전에는 표준화가 필요하다.

## 구간을 나눌 때 고려할 점

구간이 너무 짧으면 값이 자주 흔들리고, 너무 길면 짧은 전환을 놓친다. 우선 5초 Window와 2.5초 Hop으로 겹치게 자른 뒤 결과를 확인해볼 수 있다.

곡의 시작과 끝에 있는 무음도 주의해야 한다. 무음이 길면 평균 에너지가 낮아져 실제 인상과 다른 값이 나올 수 있다. 분석 전에 앞뒤 무음을 정리하거나 무음 구간임을 별도 표시하는 방법이 필요하다.

## 프로젝트에 적용한다면

- Track Feature와 Moment Feature를 다른 테이블에 저장한다.
- 모든 곡에 같은 전처리 설정을 적용한다.
- 구간별 평균값과 변화량을 함께 저장한다.
- 몇 곡의 그래프를 직접 보고 추출 결과가 청감과 맞는지 확인한다.
- 분석 코드의 버전을 기록해 특징을 다시 생성할 수 있게 한다.

처음부터 특징을 많이 넣기보다 BPM, RMS, Spectral Centroid부터 검증한 뒤 필요한 값을 추가하는 편이 관리하기 쉽다.
