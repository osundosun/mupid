# 260826 — 음악 취향 서비스 기획

## 오늘 한 일

- 기존 농작물 추천 주제에서 음악 취향 탐색 서비스로 프로젝트 방향 전환
- 곡 전체가 아닌 사용자가 좋아한 특정 순간을 취향 데이터로 활용하는 방식 구상
- 음원을 Track·Window·Moment·Scene·Track Arc 단위로 분석하는 구조 설계
- Moment DNA와 Cross-Genre Resonance를 핵심 기능으로 선정
- 실제 분석 데이터와 추천 카탈로그의 구성 방향 검토
- 자연어 검색·BPM 탐색 등 확장 기능 후보 조사

## 프로젝트 방향 전환

기존 음악 추천 서비스는 장르·아티스트·곡 전체의 분위기나 청취 이력을 중심으로 유사한 곡을 추천한다. 그러나 사용자가 한 곡의 모든 부분을 좋아하는 것은 아니며, 특정 구간의 고조·전환·리듬 변화처럼 짧은 순간에 강하게 반응할 수 있다는 점에 주목했다.

핵심 질문을 다음과 같이 정의했다.

> 사용자가 좋아한 특정 순간의 음악적 변화 패턴을 다른 곡과 장르에서도 찾을 수 있는가?

## 음원 분석 단위

곡 전체를 하나의 벡터로 표현하지 않고 시간 흐름에 따라 여러 단계로 나누어 분석하는 구조를 설계했다.

```plaintext
Track
→ Window
→ Moment
→ Scene
→ Track Arc
```

### Track

- 한 곡 전체에 해당하는 기본 단위
- 제목·아티스트·장르·길이 등 메타데이터 관리

### Window

- 음원을 일정한 길이의 짧은 구간으로 분할한 분석 단위
- 각 구간에서 BPM·Energy·Rhythm·Spectral Feature·Embedding 등을 추출
- 인접 Window의 특징 차이를 계산해 변화가 발생한 지점을 탐색

### Moment

- 사용자가 좋아요를 남긴 timestamp 전후의 짧은 구간
- 해당 시점의 절대적인 음색뿐 아니라 전후 변화량을 함께 표현
- 드롭·빌드업·악기 진입·리듬 전환·분위기 변화 같은 패턴을 포착

### Scene

- 여러 Window가 모여 형성하는 비교적 안정된 음악적 구간
- 벌스·코러스·브리지처럼 기능적으로 유사한 흐름을 표현하는 데 활용 가능

### Track Arc

- 곡 전체의 에너지와 분위기가 시간에 따라 변화하는 구조
- 비슷한 음색뿐 아니라 전개 방식이 유사한 곡을 찾는 데 활용

## Moment DNA

사용자가 특정 timestamp에 하트를 남기면 해당 지점의 앞뒤 구간을 분석해 하나의 Moment DNA로 저장하는 기능을 구상했다.

```plaintext
사용자 ❤️ timestamp
→ 전후 Window 선택
→ Audio Feature와 Embedding 추출
→ 변화량 계산
→ Moment DNA 생성
```

Moment DNA에 포함할 특징 후보:

- Energy의 상승·하강 폭
- BPM과 리듬 밀도 변화
- Spectral Centroid와 음색 변화
- 악기 구성 또는 보컬 진입 변화
- 저음·고음 에너지 변화
- 전후 구간 Embedding 차이

한 시점의 특징값만 저장하지 않고 전후 차이를 Transition Vector로 표현해 사용자가 좋아한 변화의 형태를 찾는 방향으로 정리했다.

## Cross-Genre Resonance

핵심 추천 기능은 같은 장르의 비슷한 곡을 찾는 것을 넘어 동일한 변화 패턴을 다른 장르에서 탐색하는 것이다.

예를 들어 사용자가 록 음악에서 드럼과 기타가 동시에 강해지는 순간을 좋아했다면, 전자음악의 드롭이나 클래식의 오케스트라 고조처럼 장르는 다르지만 변화 구조가 유사한 구간을 추천할 수 있다.

```plaintext
선호 Moment DNA
→ 유사 Transition Vector 검색
→ 다른 장르의 유사 Moment 탐색
→ 해당 구간부터 미리듣기 제공
```

## 데이터 구성

- FMA Full 약 879GB를 대규모 음원 분석과 모델 실험 데이터로 활용하는 방안 검토
- 실제 서비스 추천 카탈로그는 Jamendo 등 라이선스 범위가 명확한 음원으로 구성
- 분석용 데이터와 사용자에게 재생할 수 있는 음원을 분리해 저작권 위험을 줄이는 구조 선정
- 모든 음원을 실시간 분석하지 않고 미리 Window 단위 특징과 Embedding을 계산해 저장하는 배치 처리 방식 고려

## 확장 기능 후보

- 자연어로 분위기와 변화 흐름을 설명하는 음악 검색
- BPM 범위를 이용한 운동·러닝 음악 탐색
- 오디오 특징 그래프를 직접 그려 유사한 곡 찾기
- 허밍이나 음성 스케치를 이용한 검색
- 하루의 선호 Moment를 기록하는 음악일기

핵심 기능의 완성도를 우선하기 위해 초기 버전은 Moment 선택·분석·유사 구간 추천에 집중하고 나머지는 확장 후보로 정리했다.
