# 260824 — 농지 추천 서비스 기획

## 오늘 한 일

- 농지 맞춤 작물 추천 서비스의 핵심 문제와 사용자 흐름 정리
- 추천에 활용할 토지·기후·시장 데이터 구조 조사
- 흙토람·농사로·KAMIS·농넷·KOSIS·기상청 등 데이터 소스 비교
- 단순 고수익 작물 소개가 아닌 작목 전환 의사결정 서비스 방향 검토

## 서비스 방향

초기에는 고부가가치 작물과 기후변화로 새롭게 재배 가능한 작물을 추천하는 방향을 함께 검토했다. 이후 실제 농가의 관점에서 핵심 질문을 다음과 같이 정리했다.

> 현재 작물 대신 내 농지에서 어떤 작물을 재배하는 것이 더 유리한가?

추천 기준은 세 가지 축으로 구성한다.

```plaintext
토지 적합성
+
기후 적합성
+
시장성
=
작목 전환 후보
```

## 추천 기준별 데이터

### 1. 토지 적합성

- 흙토람의 작물별 토양적성도와 토양 특성 데이터 활용 검토
- 주요 변수
  - 토성
  - 배수등급
  - 유효토심
  - 경사
  - 토양 pH
  - 유기물 함량
- 토양 데이터는 변화 속도가 느리므로 실시간 분석보다 기본 적합도 산정에 활용
- 사용자가 농지 위치를 입력하면 해당 필지의 토양 조건과 작물별 요구 조건을 비교하는 방식 구상

### 2. 기후 적합성

- 기상청 과거 기후 데이터와 기후평년값 활용 검토
- 작물별 생육조건과 지역 기후를 비교하는 규칙 기반 방식 우선 고려
- 주요 변수
  - 평균·최저·최고기온
  - 강수량
  - 폭염일수와 한파일수
  - 일조시간
  - 적산온도
- 장기 기후 데이터는 모든 작물에 동일하게 적용하지 않고 재배기간과 투자기간에 따라 선택적으로 활용
- 단기 재배 작물은 최근 기후와 계절 전망을, 다년생 작물은 장기 기후 변화 가능성을 더 크게 반영하는 방향 검토

### 3. 시장성

- KAMIS·농넷·KOSIS·농업관측 자료를 통해 가격과 생산 관련 데이터 구조 조사
- 단순 가격만으로 시장성을 판단하지 않고 다음 지표를 함께 활용
  - 가격과 가격 변동성
  - 거래량과 반입량
  - 생산량
  - 재배면적
  - 생산비와 소득
- 현재 가격이 높더라도 재배면적과 생산량이 빠르게 증가하면 향후 공급과잉 위험이 있다고 판단

## 기존 서비스 조사

```plaintext
흙토람     → 토양 특성 및 작물 적합도
농사로     → 재배기술·생산비·소득 정보
KAMIS      → 농산물 가격 및 유통 정보
농넷       → 농산물 거래·시장 정보
KOSIS      → 재배면적·생산량 통계
기상청     → 과거·현재·장기 기후 데이터
```

기존 서비스는 필요한 정보를 제공하지만 각 정보가 서로 분리되어 있어 농민이 직접 찾아 종합해야 한다. 이를 하나의 흐름으로 연결해 작목 전환 후보와 판단 근거를 함께 제공하는 것을 차별점으로 설정했다.

## 서비스 차별화 방향

- 고부가가치 작물을 고정 목록으로 제공하지 않음
- 수익성과 시장 안정성의 변화에 따라 후보를 동적으로 평가
- 단순히 특정 작물을 권하는 대신 여러 후보와 추천 근거를 함께 제공
- 작목 전환을 고민하는 농가가 위험과 가능성을 비교하도록 지원
