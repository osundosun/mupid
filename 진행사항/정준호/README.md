# 정준호 — 진행사항

**주제** 농지·기후·시장 데이터 기반 작목 전환 추천 서비스  
**기간** 2026-08-24 ~

---

## 일자별 진행사항

### 2026-08-24

- **서비스 기획 및 데이터 구조 조사**
    - 농지 맞춤 작물 추천 서비스 방향 구체화
    - 추천 기준을 **토지 적합성 + 기후 적합성 + 시장성**으로 정의
    - 흙토람·농사로·KAMIS·농넷·KOSIS·기상청 등 데이터 소스 조사
    - 토양 특성, 작물 생육조건, 가격·생산량·재배면적 데이터 구조 확인
    - 고부가가치 작물을 고정 목록이 아닌 수익성·시장성 기반으로 평가하는 방향 검토
    - 장기 기후 데이터는 작물 재배기간에 따라 선택적으로 활용하는 방향 정리
    - 기존 서비스의 분산된 정보를 통합하는 **작목 전환 의사결정 서비스**로 차별화

### 2026-08-25

- **AI 기반 예측 및 추천 시스템 계획**
    - 과거 가격·생산량·재배면적·거래량을 활용한 시장 예측 구조 설계
    - 정확한 가격 예측보다 **성장·안정·과열·하락 위험 분류** 중심으로 AI 역할 정의
    - 공급과잉 및 시장 과열을 조기에 탐지하는 위험지표 설계
    - 토지·기후·시장 점수를 결합한 작물 추천 알고리즘 계획
    - 과거 시점 데이터를 이용한 Rolling Backtest 방식으로 신뢰성 검증 계획
    - 수익성·가격 변동성·생산량 변동성 등을 활용한 안정성 지표 검토
    - 최종 추천 결과를 **수익성 × 안정성 4분면**으로 제공하는 방향 설정
