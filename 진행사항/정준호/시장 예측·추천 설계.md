# 260825 — 시장 예측·추천 설계

## 오늘 한 일

- 작물 추천 과정에서 AI를 활용할 수 있는 영역 검토
- 정확한 가격 예측보다 시장 상태와 위험을 분류하는 방향으로 AI 역할 재정의
- 토지·기후·시장 점수를 결합한 추천 알고리즘 구상
- 과거 시점 데이터를 활용한 추천 신뢰성 검증 방법 검토
- 수익성과 안정성을 함께 보여주는 결과 화면 방향 정리

## AI 활용 방향

농산물 가격은 날씨·질병·수입량·정책·소비 변화 등 외부 요인의 영향을 크게 받는다. 따라서 미래 가격을 하나의 숫자로 정확히 맞히는 것을 목표로 삼기보다 시장의 흐름과 위험 수준을 구분하는 것이 서비스에 더 적합하다고 판단했다.

```plaintext
성장
안정
과열
하락 위험
```

AI 입력 데이터 후보는 다음과 같다.

- 과거 가격과 가격 변화율
- 거래량과 도매시장 반입량
- 생산량
- 재배면적과 재배의향면적
- 수입량
- 계절성과 출하시기

가격이 상승하고 거래량도 안정적으로 유지되면 성장 가능성을 높게 평가한다. 반면 가격은 높지만 재배면적과 생산량이 빠르게 증가하면 향후 공급과잉 가능성이 있으므로 과열 위험을 높게 평가하는 구조를 검토했다.

## 시장 과열 및 공급과잉 위험

단순히 현재 가격이 높은 작물을 추천하면 많은 농가가 같은 작물로 몰려 가격이 급락할 수 있다. 이를 줄이기 위해 다음 지표를 함께 확인한다.

- 최근 가격 상승률
- 재배면적 증가율
- 생산량 증가율
- 거래량 대비 반입량 변화
- 가격 변동성
- 특정 시기 생산 집중도

```plaintext
가격 상승 + 거래량 증가
→ 실제 수요 성장 가능성

가격 상승 + 재배면적 급증
→ 공급과잉 및 과열 가능성

가격 하락 + 생산량 증가
→ 하락 위험 증가
```

## 추천 알고리즘 구조

먼저 농지에서 재배 가능한 작물을 토지와 기후 조건으로 걸러낸 뒤, 시장 점수를 결합해 최종 후보의 순위를 정하는 방식을 구상했다.

```plaintext
1. 토지 조건 부적합 작물 제외
2. 기후 조건 부적합 작물 제외
3. 남은 후보의 시장성과 수익성 평가
4. 공급과잉·가격 변동 위험 반영
5. 추천 후보와 판단 근거 제공
```

추천 점수 예시:

```plaintext
종합 점수
= 토지 적합성
+ 기후 적합성
+ 시장 성장성
+ 예상 수익성
- 공급과잉 위험
- 가격 변동 위험
```

가중치는 임의로 확정하지 않고 실제 데이터 검증 결과와 서비스 목적에 따라 조정하는 방향으로 정리했다.

## 신뢰성 검증

추천 시스템의 성능은 과거 시점으로 돌아가 당시 이용 가능했던 데이터만 사용해 추천한 뒤 실제 이후 결과와 비교하는 Rolling Backtest 방식으로 검증한다.

```plaintext
과거 시점의 데이터로 추천
→ 이후 실제 가격·생산량 확인
→ 추천 결과와 비교
→ 다음 시점으로 이동해 반복
```

검증 항목은 다음과 같다.

- 추천 작물의 이후 가격과 소득 변화
- 시장 과열 또는 하락 위험 탐지 여부
- 안정 작물의 가격·생산량 변동 수준
- 단순 가격순 추천과 비교한 개선 정도

## 결과 제공 방식

사용자가 높은 수익 가능성과 위험을 동시에 비교할 수 있도록 최종 결과를 수익성과 안정성의 4분면으로 보여주는 방식을 검토했다.

```plaintext
고수익·고안정  → 우선 검토 후보
고수익·저안정  → 고위험 후보
저수익·고안정  → 안정형 후보
저수익·저안정  → 전환 우선순위 낮음
```
