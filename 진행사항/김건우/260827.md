# 260827 — 아이디어 기획 픽스 (ACCENCE, 2/2)

## 오늘 한 일

- ACCENCE 핵심 서비스 기능·차별화 기능 정리
- 빅데이터/분산처리 검증 방향, 모델 갱신 전략 확정
- 3주 MVP 범위 확정

## 핵심 서비스 기능

- **음악 감상 및 Playlist**: 재생, 연속 재생, Playlist 추가/제거, Track 좋아요, 재생 히스토리
- **Moment 기반 추천**: 좋아한 구간 또는 Replay/Seek-back이 반복된 구간 기준으로 유사한 음악 흐름 탐색
- **Listening DNA + 청각 페르소나**: 분석 결과를 수치가 아닌 성향으로 변환 (예: "시네마틱 몰입자" — Slow Build 41% / Wide Release 28% / Rhythm Collapse 19%, 대표 Moment 함께 제공)

## 추가 차별화 기능

- **BPM 탐색**: 직접 숫자 입력, Slider, Tap Tempo로 원하는 BPM 지정 → 해당 BPM 대역 음악 추천 (러닝/트레드밀 등 사용처 고려)
- **오디오 그래프 드로잉 탐색**: 사용자가 원하는 에너지·전개 흐름을 곡선으로 직접 그려 검색 — 그린 Curve를 정규화 후 기존 곡의 Energy/Transition Curve와 비교. 자연어 추천과 달리 음악의 **시간적 전개 자체**를 검색 조건으로 사용하는 대표 차별화 기능으로 설정

## 빅데이터·분산처리 방향

- FMA 879GB 처리 자체를 분산처리 명분으로 삼지 않고, **사용자 증가에 따라 누적되는 청취 행동 데이터 처리 + Listening DNA/추천 Profile 갱신**에 분산처리를 적용
- 실제 팀원 6명의 서비스 사용 로그(Session 길이, Play 수, Skip 비율, Seek/Replay 빈도, Moment Like 비율 등 분포)를 기반으로 1,000 → 10,000 → 100,000 사용자 규모의 **Synthetic Event Data**를 생성해 부하·확장성 실험에 사용

## 분산처리 검증 방법

- Baseline → Bottleneck 확인 → Distributed Processing 적용 → Re-test 순서로 검증
- Event 규모(100K/1M/10M/100M)별로 Single vs Distributed 처리 시간, Events/sec, CPU/Memory 사용량, Join/Aggregation 시간, Listening DNA 갱신 시간, Worker 증가에 따른 Speed-up 측정
- "빅데이터 프로젝트라서 분산처리를 적용했다"가 아니라 **어느 규모부터 분산처리가 실제로 효과적인지 직접 측정**하는 것이 목표

## 모델 및 추천 갱신 전략

- Audio Embedding을 만드는 Pretrained Encoder는 비교적 고정적인 영역 — 트렌드 변화마다 재학습할 필요 없음
- User Event → Preference Weight → Listening DNA → Recommendation Ranking은 지속적으로 갱신되는 영역
- 오디오 모델 자체 재학습보다 **사용자 Preference Layer를 지속 업데이트**하는 구조를 기본으로 설정

## 3주 MVP 범위

- **필수 구현**: Jamendo 카탈로그 확보, Track/Moment Audio Feature 추출, 스트리밍/Playlist, User Event 수집, 기본 추천, Moment 기반 추천, Listening DNA, 청각 페르소나, 대규모 Event Processing 실험
- **우선순위 높은 추가 기능**: BPM 탐색, 오디오 그래프 드로잉 탐색
- **후순위/확장 기능**: 자연어 음악 추천, 이미지 기반 추천, SUNO Prompt 생성, 보컬 스케치 검색, 음말잇기, 음악일기, Context/날씨 기반 추천
- 3주 내 여러 추천 기능을 모두 구현하기보다 **행동 → 취향 분석 → 추천 → 반응 → 추천 개선**이라는 하나의 추천 Cycle 완성을 우선순위로 설정

## 핵심 요약

- Jamendo 실서비스 가능 음원으로 카탈로그를 구성하고, 재생·Skip·Replay·Seek·좋아요·Moment 반응을 수집해 Listening DNA 생성
- 구간 선택은 필수 입력이 아닌 취향을 정교화하는 추가 신호
- 대규모 행동 이벤트 + 음원 특징 결합으로 추천 Profile을 계산하고, 팀 실사용 로그 기반 Synthetic Event로 분산처리 효과를 검증
- '음악 데이터를 많이 분석한 프로젝트'가 아니라 '행동이 쌓일수록 추천이 정교해지는 빅데이터 기반 음악 추천 서비스'를 지향
