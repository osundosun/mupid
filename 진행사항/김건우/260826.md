# 260826 — 아이디어 기획 픽스 (ACCENCE, 1/2)

## 오늘 한 일

- 최종 아이디어를 **ACCENCE** (사용자 청취 행동 기반 음악 취향 탐색·추천 서비스)로 픽스
- 서비스 정의, 데이터 구성, 음원 분석 기준, 사용자 행동 데이터, Listening DNA, 구간 기반 추천 구조 정리

## 서비스 한 줄 정의

> 청취 행동과 좋아한 음악 구간을 분석해 개인 취향을 정교화하고, 비슷한 흐름의 새로운 음악을 추천하는 서비스

기존 추천이 곡·장르·아티스트 단위 선호 분석 중심이라면, ACCENCE는 여기에 **실제 청취 행동**과 **곡 내부 구간 반응**을 더한다. 사용자가 구간을 직접 선택하지 않아도 전체 감상/좋아요/Skip/Replay/Seek/Playlist 저장/Moment 좋아요 등 행동을 종합해 기본 취향을 만들고, 명시·암묵 반응이 쌓일수록 세밀한 **Listening DNA**를 생성한다.

## 데이터 구성

- 기존 FMA Full(879GB) 중심에서 벗어나, 서비스에 실제 사용 가능한 **Jamendo 라이선스 허용 음원**을 카탈로그로 사용 (목표 약 5,000~10,000곡)
- 수집 기준: 서비스/분석 가능 라이선스, Popularity, Featured, 장르 다양성, Vocal/Instrumental 포함, Artist/Album 중복 제한
- Jamendo 음원은 분석용과 서비스용을 분리할 필요 없이 그대로 사용 (수집 → 분석 → 추천 → 행동 축적 → 추천 정교화)
- FMA는 필요 시 오디오 분석 실험용 보조 데이터로만 활용, 서비스 핵심/분산처리 명분에서 제외

## 음원 분석 기준

- **Track-level**: BPM, Energy, Rhythm, Timbre/Spectral Feature, Audio Embedding, Vocal Presence, Genre/Metadata
- **Moment-level**: 곡을 일정 Window(예: 5초 단위)로 나눠 Audio Embedding·Energy·Rhythm·Timbre를 추출하고 인접 Window 간 변화량을 계산 (예: Energy 0.18→0.24→0.41→0.73→0.89, Rhythm Low→Low→Medium→High→High → Gradual Build → Release로 해석)
- 핵심은 특정 구간의 음향 유사성이 아니라 **그 순간에 도달하기까지의 흐름**을 비교하는 것

## 사용자 행동 데이터

- 수집 후보: PLAY, PAUSE, SKIP, SEEK, SEEK_BACK, REPLAY, TRACK_LIKE, MOMENT_LIKE, PLAYLIST_ADD, PLAY_COMPLETE, RECOMMENDATION_CLICK, FULL_TRACK_CONVERSION
- 명시적 좋아요 없이도 같은 구간을 반복 Seek-back/재감상하면 Implicit Positive Signal로 활용, 추천 구간을 곧바로 Skip하면 Negative Signal로 처리
- Moment 선택은 추천의 필수 조건이 아니라 취향을 세밀화하는 고해상도 피드백으로 사용

## Listening DNA와 추천 구조

- Track Preference(Genre/BPM/Energy/Vocal-Instrumental) + Moment Preference(Gradual Build/Wide Release/Rhythm Collapse/Sudden Expansion)로 다단계 취향 Profile 구성
- 추천 파이프라인: Candidate Generation → Track/Moment Similarity → User Preference Score → Skip/Replay/Like Weight → Diversity → Final Ranking

## 구간 기반 추천

- 특정 timestamp에 좋아요를 누르면 해당 지점 전후 구간(예: 01:22~02:02)을 Window 단위로 분석해 Moment/Transition Vector 생성
- Jamendo 카탈로그에 미리 분석해 둔 구간 Vector와 유사도 검색을 수행해 "이 곡의 03:17부터 들어보세요" 식으로 곡 제목이 아닌 **구간 단위** 추천 결과를 제공
