# 260825 — React 컴포넌트와 Text-to-SQL 입력 폼

## 학습 목표

- Skeleton-2 Text-to-SQL의 `db_id`, `question`, `query` 구조를 프론트엔드 UI에 연결한다.
- React Controlled Component와 TypeScript 이벤트 타입으로 폼 상태를 관리한다.
- 입력값 검증과 접근성 오류 안내를 구현한다.

## 진행 내용

- 명세서와 Skeleton-2 데이터 구조 확인
- 입력 화면의 데이터 흐름과 컴포넌트 구조 설계
- `useState<QueryRequest>`, Props, `ChangeEvent`, `FormEvent` 학습
- 데이터베이스 선택과 자연어 질문 입력 폼 구현
- 예시 질문 선택 시 데이터베이스와 질문 동시 변경
- 질문 미입력, 공백, 최소 10자, 최대 240자 유효성 검사
- 폼 제출 데이터를 Mock SQL 결과 화면과 연결

## 명세서와 프론트엔드 연결

| Skeleton-2 필드 | 프론트엔드 구현 |
|---|---|
| `db_id` | `DatabaseSelect`에서 질의 대상 데이터베이스 선택 |
| `question` | Controlled `textarea`로 자연어 질문 입력 및 검증 |
| `query` | 제출된 요청의 생성 SQL과 결과 테이블 표시 |

## 적용한 React·TypeScript 개념

- `useState<QueryRequest>` Generic으로 폼 상태 구조 고정
- `ChangeEvent<HTMLSelectElement>`와 `ChangeEvent<HTMLTextAreaElement>` 적용
- `FormEvent<HTMLFormElement>`와 `preventDefault()`를 이용한 폼 제출
- Props 콜백으로 자식 컴포넌트의 입력을 상위 데이터 흐름에 전달
- `aria-invalid`, `aria-describedby`로 오류 메시지와 입력 요소 연결

## 문제 해결

예시 질문을 선택하면 질문뿐 아니라 대상 데이터베이스도 함께 바뀌어야 했다. 예시를 `ExampleQuestion` 타입으로 정의하고 `dbId`와 `question`을 하나의 객체로 갱신하도록 해결했다.
