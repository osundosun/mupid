# 260825 — React 입력 폼

## 학습 목표

- Skeleton-2의 `db_id`, `question` 구조를 입력 폼에 연결한다.
- Controlled Component 방식으로 폼 상태를 관리한다.

## 진행 내용

- 명세서와 Skeleton-2 요청 필드 확인
- 데이터베이스 선택과 자연어 질문 입력 UI 구현
- `useState<QueryRequest>`로 입력값 관리
- Select, Textarea, Form 이벤트에 TypeScript 타입 적용
- 빈 질문 검증 후 Mock 결과 화면과 연결

## 명세서와 프론트엔드 연결

| Skeleton-2 필드 | 프론트엔드 구현 |
|---|---|
| `db_id` | Select에서 대상 데이터베이스 선택 |
| `question` | Textarea에서 자연어 질문 입력 |
| `query` | 제출 후 생성 SQL과 결과 표시 |

## 적용한 React·TypeScript 개념

- `useState`를 이용한 입력 상태 관리
- `ChangeEvent`, `FormEvent` 이벤트 타입
- Props 콜백을 이용한 폼 제출
- `aria-invalid`를 이용한 입력 오류 표시

## 문제 해결

공백만 입력한 질문이 제출되지 않도록 `trim()`으로 값을 확인하고, 유효한 질문만 상위 컴포넌트로 전달했다.
