# 260824 — TypeScript와 프로젝트 구조

## 학습 목표

- React + TypeScript 기반 Text-to-SQL 학습 화면의 구조를 설계한다.
- TypeScript의 주요 타입 문법을 API 요청과 응답 구조에 적용한다.
- 실제 백엔드 없이 확인할 수 있는 Mock 결과 화면을 구현한다.

## 진행 내용

- 최종 화면 스케치와 필요한 컴포넌트 정리
- Vite React + TypeScript 프로젝트 생성 및 ESLint 구성 확인
- `type`, `interface`, union type, optional property 학습
- 함수 인자와 반환 타입, `Record`, Generic 기초 학습
- API, 컴포넌트, 훅, Mock, 타입, 유틸리티 디렉터리 분리
- Text-to-SQL Mock 응답과 동적 결과 테이블 구현

## 적용한 TypeScript 개념

- `RequestStatus` union type으로 요청 상태의 허용값 제한
- `QueryRequest`, `QueryResult` interface로 요청·응답 계약 정의
- `Record<string, string | number | null>`로 컬럼이 달라지는 SQL 행 표현
- `ApiResponse<T>` Generic으로 재사용 가능한 공통 응답 타입 작성
- 함수 반환 타입을 명시해 API 계층과 화면 계층 사이의 데이터 구조 확인

## 데이터 흐름

```text
자연어 질문 → API 요청 → SQL 응답 → SQL 코드 + 결과 테이블
```

## 문제 해결

SQL 결과는 질의마다 컬럼 이름이 달라 고정된 interface만으로 표현하기 어려웠다. 행을 `Record<string, string | number | null>`로 정의하고 `columns` 배열 순서에 따라 셀을 렌더링하도록 구성했다.

## 산출물

- React + TypeScript 기본 프로젝트 구조
- 요청·응답 TypeScript 타입
- Generic API 응답 타입
- Text-to-SQL Mock 데이터
- 생성 SQL과 동적 결과 테이블 화면
