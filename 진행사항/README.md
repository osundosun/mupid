# 진행사항

팀원별 폴더에 일자별 진행사항을 기록한다.

## 구조

```
진행사항/
├── 곽도연/README.md
├── 김건우/README.md
├── 안규리/README.md
├── 이규원/README.md
├── 정예준/README.md
└── 정준호/README.md
```

## 규칙

- 폴더명은 한글 풀네임
- 각 폴더의 `README.md`에 `### YYYY-MM-DD` 형식으로 날짜 항목을 추가해 기록
- 파일은 본인 폴더 안에만 둔다
