# 외부 서비스

프로젝트가 가입하거나 설정해서 쓰는 외부 서비스를 정리했다. **비밀값은 적지 않는다.** 키 이름과 주입 위치만 적는다.
운영 Secret·CI 변수 전체 표는 [infra/README.md](infra/README.md) 5장과 [infra/ci/VARIABLES.md](../infra/ci/VARIABLES.md)에 있다.

## 1. 소셜 로그인 — 사용하지 않음

`api/src`, `frontend/src`, `app/src` 어디에도 Kakao·Naver·Google OAuth 로그인 코드가 없다.
인증은 이메일·비밀번호 가입 + 메일 인증 + 자체 JWT다
([AuthProvider.java](../api/src/main/java/com/osundosun/mupid/api/auth/provider/AuthProvider.java), 키 `MUPID_JWT_SECRET`).
따라서 OAuth 앱 등록이나 redirect URI 설정이 필요 없다.

## 2. Google Gmail API — 인증 메일 발송

| 항목 | 내용 |
|---|---|
| 용도 | 이메일 인증번호 메일 발송 (발신자 표시명 "뮤피드") |
| 모듈 | [common/gmail/](../api/src/main/java/com/osundosun/mupid/api/common/gmail/) (`GmailConfig`·`GmailProvider`), [EmailServiceImpl.java](../api/src/main/java/com/osundosun/mupid/api/email/service/EmailServiceImpl.java) |
| 방식 | `google-api-services-gmail` + OAuth2 `UserCredentials`(client id/secret + **refresh token**)로 `users.messages.send("me")` 호출 |
| 설정 | [application.yaml](../api/src/main/resources/application.yaml) `gmail.*` |

**가입·설정 방법**

1. Google Cloud Console에서 프로젝트를 만들고 **Gmail API**를 사용 설정한다.
2. OAuth 동의 화면을 구성하고, 발신에 쓸 Gmail 계정을 테스트 사용자(또는 게시)로 둔다.
3. 사용자 인증 정보 → **OAuth 클라이언트 ID**를 만든다.
4. 발신 계정으로 동의해 **refresh token**을 받는다 (메일 발송 권한 scope).
5. 아래 네 키를 채운다.

| 키 | 주입 위치 |
|---|---|
| `MUPID_GMAIL_CLIENT_ID` · `MUPID_GMAIL_CLIENT_SECRET` · `MUPID_GMAIL_TOKEN`(refresh token) · `MUPID_GMAIL_SEND_ADDRESS` | 로컬 [api/.env.example](../api/.env.example) → `api/.env` / 운영 GitLab File 변수 `MUPID_API_ENV` → Secret `mupid-secrets` ([api.yaml](../infra_k8s/base/api.yaml)) |

> TODO: 팀 확인 — OAuth 클라이언트 유형(데스크톱/웹), refresh token을 받을 때 쓴 scope·redirect URI, 발신 계정. 저장소에는 토큰 발급 절차가 없다.

## 5. Firebase Crashlytics — 앱 예외 보고

| 항목 | 내용 |
|---|---|
| 용도 | Tauri Android 앱(`com.osundosun.mupid`)의 크래시·경고 보고 |
| 모듈 | [app/src/crash.rs](../app/src/crash.rs), [CrashlyticsPlugin.kt](../app/gen/android/app/src/main/java/com/osundosun/mupid/CrashlyticsPlugin.kt), [app/gen/android/app/build.gradle.kts](../app/gen/android/app/build.gradle.kts) (`com.google.gms.google-services`, `com.google.firebase.crashlytics`) |
| 빌드 | [infra/ci/build-apk.sh](../infra/ci/build-apk.sh)가 base64 값을 `app/gen/android/app/google-services.json`으로 복원 |

**가입·설정**

1. Firebase 콘솔에서 프로젝트를 만들고 Android 앱을 패키지명 `com.osundosun.mupid`로 등록한다.
2. Crashlytics를 사용 설정하고 `google-services.json`을 내려받는다 (커밋 금지, [app/.gitignore](../app/.gitignore)가 막음).
3. `base64 -w0 app/gen/android/app/google-services.json` 결과를 CI 변수에 넣는다.

| 키 | 주입 위치 |
|---|---|
| `GOOGLE_SERVICES_JSON_BASE64` (없으면 `app-build` 실패) | GitLab File 변수 `MUPID_APP_ENV` ([app/deploy.env.example](../app/deploy.env.example)) |
| `MUPID_CRASHLYTICS_ENDPOINT` · `MUPID_CRASHLYTICS_API_KEY` (구 경로, SDK 전환 후 불필요) | 같은 곳 / 로컬 [app/.env.example](../app/.env.example). 컴파일 시점에 박힘 |

같은 파일에 들어가는 APK 서명 값: `ANDROID_KEY_ALIAS`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEYSTORE_BASE64`, `MUPID_API_ORIGIN`.
**원본 `.jks`는 따로 백업한다** — 잃으면 같은 앱으로 업데이트할 수 없다.
