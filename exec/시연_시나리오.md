### 장면 1. 시작 화면

| 항목 | 내용 |

| 보여줄 포인트 | 비로그인이면 로그인 대화상자가 뜬다. 우측 상단에서 라이트/다크 테마를 바꿀 수 있다 |

### 장면 2. 회원가입 (이메일 인증)

| 항목 | 내용 |
| --- | --- |
| 경로 | `/signup` (대화상자, 제목 "뮤피드 회원가입") |
| 동작 | ① 로그인 대화상자 아래의 **회원가입** 버튼. ② 이메일 입력 → **이메일 인증하기** → 메일로 받은 6자리를 "인증 번호"에 입력 → **인증 확인**. ③ 비밀번호, 비밀번호 확인, 닉네임(최대 10자), 출생 연도, 성별(남성/여성/기타) 입력. ④ 하단 **회원가입** |
| 보여줄 포인트 | 인증 전에 가입하면 "이메일 인증을 먼저 완료해 주세요." 경고가 뜬다. 가입이 끝나면 "회원가입이 완료됐어요. 로그인해 주세요."가 나오고 로그인 모드로 돌아간다 |
