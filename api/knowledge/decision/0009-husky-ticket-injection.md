# 0009. 커밋 티켓 번호를 husky 훅으로 자동 삽입한다

**상태** 채택 · 기계로 강제되는 유일한 규약

## 맥락

지라 티켓과 커밋을 손으로 연결하면 빠뜨린다. 2026-09-04 회고에서 정예준의 Try 가 *"Git 커밋 후 자동으로 지라 티켓 연결해주는 자동화 시도"* 였고, 3일 뒤 훅이 들어왔다 (`f205ec5`, 2026-09-07).

## 결정

`.husky/commit-msg` 가 **브랜치명에서** 티켓 번호를 뽑아 커밋 제목 끝에 `(S15P21A204-N)` 형태로 붙인다.

- 브랜치명에 `S15P21A204-<숫자>` 가 없으면 **커밋을 거부한다.**
- 예외: 회고 봇의 자동 커밋, merge/squash 커밋, rebase·cherry-pick·revert 진행 중, 제목에 이미 티켓이 있는 경우.
- 최초 1회 프로젝트 루트에서 `npm install` 을 해야 훅이 설치된다.

## 결과

- 티켓 누락이 구조적으로 불가능해졌다.
- **브랜치명이 커밋의 전제가 됐다.** 티켓 없는 브랜치에서는 커밋 자체가 안 된다.
- 소괄호 `(...)` 가 훅이 넣는 형식이다. 과거 훅은 대괄호 `[S15P21A204-N]` 를 넣었고, 이력에는 두 형태가 섞여 있다.
- 훅은 로컬에만 설치된다. `npm install` 을 안 한 사람에게는 아무것도 강제되지 않는다.
